# Review of *Fundamental Accelerator Physics* (JB2) — 2026-09-08

Scope: all 11 pages under `content/`, plus `myst.yml`, `README.md`, `content/index.md`.

Overall this is already a strong set of notes. The physics narrative is well
sequenced, the prose is unusually good (each widget is introduced with *why* it
exists and closed with *what you should have seen*), and the TrackPad widgets are
a genuine differentiator. The gaps below are mostly (a) a handful of real physics
and notation errors, (b) missing course scaffolding — exercises, references,
numbered equations, a symbol table, and (c) build robustness.

Items are tagged **[bug]** (wrong or broken), **[gap]** (missing content),
**[polish]** (clarity/consistency).

## 1. Physics and mathematics errors

### 1.1 `math_prep/linear_algebra.md`

- **[bug]** Opening sentence: "an $m\times n$ matrix connecting an input of
  dimension $m$ and a response of dimension $n$." This is backwards — an
  $m\times n$ matrix maps an input of dimension $n$ to a response of dimension
  $m$. First sentence of the book's first technical page; worth fixing.
- **[polish]** Eigensystem section switches from $n$ to $N$ mid-paragraph.
- **[bug]** Closing claim: "For $|\mathrm{Tr}\,M|\le 2$ … the motion repeats
  forever without growth." At $|\mathrm{Tr}\,M| = 2$ exactly, the eigenvalues are
  degenerate at $\pm1$ and $M^k$ grows *linearly* in $k$ unless $M=\pm I$. State
  the condition as strict ($<2$) and add one sentence on the marginal case — it
  matters, because it is exactly the FODO $L_1/f=2$ limit you illustrate later.

### 1.2 `math_prep/oscillators_vector_calculus.md`

- **[bug]** The ODE taxonomy writes $\frac{dx}{dt}+b(x)=0$ and
  $\frac{d^2x}{dt^2}+a(x)\frac{dx}{dt}+b(x)=0$. Coefficients written as functions
  of $x$ make these *nonlinear* equations, which is not what you go on to solve.
  Should be $a(t)\,x' + b(t)\,x$ — and that also sets up Hill's equation, where
  the coefficient is a function of $s$, much more cleanly.
- **[polish]** $x=Ae^{i\omega t}+Be^{-i\omega t}=A\cos(\omega t+\phi_0)$ reuses
  $A$ for two different constants.
- **[polish]** Gauss's theorem is stated as $\int_S \mathbf f\cdot d\mathbf S=\int_V \nabla\cdot\mathbf f\,dV$
  without saying $S=\partial V$ is closed. Same for the Maxwell table's surface
  integrals (use $\oiint$ or say "closed surface").
- **[bug/build]** This page uses `arrows!` while
  `transverse_dynamics/fields_multipoles_orbit.md` uses `arrows2d!`. In Makie
  ≥ 0.22 `arrows!` is deprecated in favour of `arrows2d!`/`arrows3d!` and emits a
  warning (or fails, depending on version). Pick one and use it everywhere.

### 1.3 `math_prep/relativistic_mechanics.md`

- **[polish]** "which can be viewed as the object being 'heavier' by a factor of
  $\gamma$" — the relativistic-mass picture is generally discouraged and breaks
  immediately for transverse vs longitudinal acceleration (which is precisely the
  $\gamma$ vs $\gamma^3$ asymmetry your linac chapter depends on). Suggest
  replacing with a footnote saying exactly that, and forward-referencing the
  $\beta^3\gamma^3$ factor in `linac_dynamics.md`.
- **[gap]** No mention of proper time or the invariant interval, and the
  four-vector section stops at the definition. One line — "$\mathbf P\cdot\mathbf P=(mc^2)^2$
  is why $E^2-P^2c^2$ is frame-independent" — would tie the section to the
  widget that follows it.

### 1.4 `transverse_dynamics/fields_multipoles_orbit.md`

- **[bug]** The Beth/US multipole expansion
  $B_y+iB_x=B_0\sum(b_n+ia_n)(x+iy)^n$ is **dimensionally inconsistent**: the
  US convention normalizes by a reference radius,
  $B_y+iB_x = B_0\sum (b_n+ia_n)\left(\frac{x+iy}{r_0}\right)^n$, so that $b_n,a_n$
  are dimensionless (and conventionally quoted in "units" of $10^{-4}$). As
  written, $b_1$ has units of m$^{-1}$, $b_2$ of m$^{-2}$, etc. Students who go
  on to read a magnet measurement report will be confused. Add $r_0$ and one
  sentence about the $10^{-4}$ convention.
- **[gap]** Related: you say "$k_2$ is not pre-divided by factorials" for
  TrackPad, but never give the dictionary between $b_n$, $k_n$, and the MAD-X /
  Elegant conventions. A small table
  ($k_n = \frac{n!\,b_n B_0}{B\rho\,r_0^n}$ vs MAD-X `Kn`) would save every
  student in the class an afternoon.
- **[bug]** "The momentum change lies purely in the $x$–$s$ plane; the velocity
  stays perpendicular to $\mathbf B$, so the energy does not change." The energy
  is constant because $\mathbf F\perp\mathbf v$ (magnetic forces do no work), not
  because $\mathbf v\perp\mathbf B$. Reword.
- **[polish]** The magnetic-vs-electric table has no caption explaining that
  $E=\beta c B$; add it, and add the practical breakdown number (~10 MV/m DC,
  ~30 MV/m with careful conditioning) that justifies the conclusion.
- **[gap]** The multipole table lists solenoids under "Magnet type … grouped by
  the order of the multipole expansion", but a solenoid is *not* a transverse
  multipole. Either separate it or add a note.

### 1.5 `transverse_dynamics/linear_motion_matrices.md`

- **[bug/major]** The book never reconciles $x'$ (used in every analytic formula)
  with $p_x$ (used in every TrackPad plot axis label). They differ by a factor
  $(1+\delta)$ (and by $P_0$ normalization). Several figures are labelled
  `px [rad]`, which is neither. This is the single most likely source of student
  confusion in the whole book. Fix by adding a short boxed subsection —
  "Slopes vs canonical momenta" — the first time TrackPad coordinates appear, and
  then labelling axes consistently.
- **[polish]** "Dipole (horizontal plane)" transfer matrix is specifically the
  **sector** bend. Say so, note that the vertical plane is a drift for a pure
  sector dipole, and add the rectangular-bend edge-focusing matrix
  $\begin{pmatrix}1&0\\ \tan(\psi)/\rho&1\end{pmatrix}$ — you already mention
  rectangular dipoles in the previous chapter but never give their matrix.
- **[gap]** The $3\times3$ form including dispersion
  ($(x,x',\delta)$ with the $\rho(1-\cos\theta)$ entry) is never given, even
  though the dispersion section later needs it. Add it here.
- **[bug]** Stability derivation: "eigenvalues $\lambda$ of $M$ must satisfy
  $|\lambda|\le1$." With $\det M=1$ the eigenvalues satisfy $\lambda_1\lambda_2=1$,
  so $|\lambda|\le 1$ for both forces $|\lambda|=1$. Saying this explicitly is a
  one-line improvement that makes the argument airtight.
- **[bug]** `optics4DUC(100.0, 100.0, 100.0, 100.0)` in the big drift-tracking
  cell: this sets $\alpha_x=\alpha_y=100$ with $\beta=100$ m, which is an extreme
  and almost certainly unintended entrance condition (I suspect
  `(100, 0, 100, 0)` was meant). Check the resulting figure.
- **[polish]** Two consecutive cells demonstrate the *same* physics (a bunch
  shearing through a 2 m drift). The second is ~130 lines of Makie layout code.
  Recommend deleting the first and keeping the second, or vice versa — one drift
  demo is enough, and the duplication costs build time.
- **[polish]** `beam = Beam(3.0e9)` is defined at top level in the *middle* of
  this page and then relied on by later cells and by
  `emittance_coupling_dispersion.md`'s later cells. This is fragile: any
  reordering or partial execution breaks the build with a confusing
  `UndefVarError`. Define shared setup once, in a clearly labelled cell at the
  top of each page.
- **[polish]** `track_s` is defined three separate times (here, in
  `fields_multipoles_orbit.md`, and in `emittance_coupling_dispersion.md`).
  Promote it into `TrackPadWidgets` (or a small `book_utils.jl`) and `using` it.

### 1.6 `transverse_dynamics/twiss_fodo.md`

- **[bug]** $\beta = m_{12}/\sin\Phi$ and $\alpha=(m_{11}-m_{22})/(2\sin\Phi)$
  are given without fixing the **sign of $\Phi$**. $\cos\Phi=\tfrac12\mathrm{Tr}M$
  determines $\Phi$ only up to sign; the physical branch is fixed by requiring
  $\beta>0$, i.e. $\mathrm{sign}(\sin\Phi)=\mathrm{sign}(m_{12})$. Your own code
  (`xtune` in `linear_motion_matrices.md`) *does* handle this
  (`M[1,2] < 0 ? 1-Q : Q`) but the text never explains it. Add one sentence — it
  is the classic tune-above/below-half-integer trap.
- **[gap]** The Twiss functions are *asserted*, never derived. There is no
  mention of the envelope (Courant–Snyder) equation
  $\tfrac12\beta\beta''-\tfrac14\beta'^2+\beta^2 K=1$, no $\alpha=-\beta'/2$, and
  no $\psi(s)=\int ds/\beta$. $\psi$ is used in the $M(s_1|s_0)$ formula without
  ever being defined. This is a significant hole in the central chapter of the
  book — at minimum define $\alpha \equiv -\beta'/2$ and
  $\psi(s)\equiv\int_0^s ds/\beta$, and state the envelope equation even if you
  don't derive it.
- **[gap]** $J$ is called "the action" and used throughout, but the
  Courant–Snyder invariant $2J=\gamma x^2+2\alpha xx'+\beta x'^2$ is only ever
  written inside a code comment. Promote it to a displayed, labelled equation.
- **[gap]** Beam size $\sigma_x=\sqrt{\beta\epsilon}$ (and, with dispersion,
  $\sigma_x=\sqrt{\beta\epsilon+(D\sigma_\delta)^2}$) never appears anywhere in
  the book. This is the single most-used formula in practical accelerator work.
- **[polish]** `tw.mux .% (2π)` uses `rem`; `mod` is safer if any phase is ever
  negative. Also the resulting sawtooth plot is not obviously informative —
  consider plotting unwrapped $\mu_x(s)/2\pi$ instead, which shows the tune
  directly as the endpoint.
- **[polish]** The thin-lens comparison in the TrackPad FODO cell uses
  $\Phi = 2\arcsin\!\big(\tfrac{L_{\rm cell}/2}{2f}\big)$, but the thick-quad
  ring starts at the QF *entrance* while the analytic formula assumes the QF
  *midpoint*. Say that the ~few-percent disagreement is expected and why.

### 1.7 `transverse_dynamics/emittance_coupling_dispersion.md`

- **[bug/build]** In the first `{code-cell}`, `fig` is followed by two `println`
  lines. Jupyter displays only the **last** expression of a cell, so the figure
  will not render — the cell will emit the two printed lines and no plot. Move
  `fig` to the end (or wrap in `display(fig)`).
- **[bug/reproducibility]** That same cell calls `randn` without seeding, so the
  scatter plot and the printed "measured $\epsilon_{rms}$" change on every build.
  Add `Random.seed!(...)` as you do elsewhere.
- **[gap/major]** **Normalized emittance is never defined.** $\epsilon_n=\beta\gamma\epsilon$
  and adiabatic damping $\epsilon\propto1/(\beta\gamma)$ are foundational and are
  what make the "emittance is conserved" statement true. Add a subsection.
- **[gap]** Liouville's theorem is never stated. It is the reason emittance is
  invariant and the reason symplecticity matters — it deserves an explicit box,
  along with the standard caveats (radiation damping, scattering, space charge
  are the exceptions).
- **[bug]** Solenoid factorization: "$M_{sol}=M_{\text{focus}}M_{\text{rotation}}M_{\text{focus}}$:
  two equal-strength focusing lenses acting on both planes separated by a
  rotation." The standard hard-edge result is a *rotation by the Larmor angle
  composed with a focusing block* — the entrance and exit fringe fields supply
  thin angular kicks $\Delta x'=+g_s y$, $\Delta y'=-g_s x$, and the body is a
  rotation. Please double-check this factorization against your source; as
  written I do not think it is right, and in any case the physical origin of the
  coupling (the *fringe* kick) is the part students need and it is not mentioned.
- **[gap]** The coupling section is called a "primer" and stops at the solenoid.
  Either add the minimal coupled-optics vocabulary (normal modes, the difference
  resonance, $\Delta Q_{\min}$, skew-quad correction) or state explicitly in the
  index that coupled optics is out of scope for this course.
- **[polish]** `disp_ring` bends by a total of $\pi/4$, so it is not a closed
  ring; calling it a "ring" and contrasting with "a bend-free ring" is loose.
  Call it a periodic *cell*.
- **[gap]** Chromaticity: the natural-chromaticity integral
  $\xi_{\rm nat}=-\frac{1}{4\pi}\oint\beta(s)k(s)\,ds$ appears **only inside a
  widget `note` string**. Derive or at least display it in the main text. Also
  state the convention explicitly ($\xi = d\nu/d\delta$ vs the normalized
  $\xi=\frac{1}{\nu}\frac{d\nu}{d\delta}$) — both are in common use and they
  differ by a factor of the tune.
- **[gap]** No mention of why chromaticity must be corrected at all (head–tail
  instability, and the tune-footprint/resonance-crossing argument). One paragraph
  would make the sextupole section land.

### 1.8 `longitudinal_dynamics/rf_acceleration.md`

- **[bug]** "The envelope potential is $\int_{-\infty}^{\infty}E_0(s)\,ds$" — this
  is a *voltage*, not a potential, and the sentence is orphaned. More importantly,
  the relation that defines $V$, namely
  $$V = T\int_{-\infty}^{\infty}E_0(s)\,ds,$$
  is **never written down**. The text says "defining the equivalent cavity voltage
  $V$ and the transit-time factor $T$" but only displays the formula for $T$.
  Add the $V$ equation.
- **[bug]** Similarly, the relation between the running phase $\phi$ and the
  synchronous phase, $\phi = \phi_s - \dfrac{\omega z}{\beta c}$, is used
  implicitly in $\Delta U=eV\sin\phi$ but never displayed. Without it the jump
  from the integral to $eV(\sin\phi-\sin\phi_s)$ is a leap.
- **[gap]** No numbers. A sentence on typical values (normal-conducting ~1–5
  MV/m at a few hundred MHz; SRF 15–30 MV/m at 650 MHz–1.3 GHz; $T\approx0.7$–0.9
  for a practical gap) would anchor everything.
- **[gap]** $R/Q$, shunt impedance and $Q_0$ are not mentioned even in passing —
  reasonable for a "fundamentals" course, but say so.

### 1.9 `longitudinal_dynamics/ring_longitudinal_map.md`

- **[bug]** Pendulum analogy table: for $H=\tfrac12 h\omega_0\eta\,\delta^2+\dots$
  compared to $H=\tfrac12 m v^2+\dots$, the mass analogue is $1/(h\omega_0\eta)$,
  not $h\omega_0\eta$. The table row **"'Mass' | $h\omega_0\eta$ | $m$" is
  inverted.**
- **[bug]** Longitudinal phase-space area:
  $\mathcal A_{rms}=\pi\sqrt{\langle\Delta E\rangle^2\langle\Delta t\rangle^2-\overline{\Delta E\Delta t}^2}$
  — $\langle\Delta E\rangle$ is the *mean*, which is zero by construction. These
  should be second moments: $\langle\Delta E^2\rangle\langle\Delta t^2\rangle$, or
  better $\sigma_E^2\sigma_t^2$. Same for the $\approx\pi\langle\Delta E\rangle\langle\Delta t\rangle$
  that follows.
- **[bug/polish]** The RHIC parameter table says "Injection energy 20 GeV
  (kinetic)", but the code uses `E0_tot = 20e9` as **total** energy. Both give
  $\gamma<\gamma_{tr}$ so the physics conclusion survives, but the labelling is
  inconsistent. While you're there: add $\gamma_{tr}=1/\sqrt{\alpha_c}=23.6$ to
  the table — it is the number the whole section turns on.
- **[gap]** **Transition crossing is never discussed.** The book sets up
  $\eta$, $\gamma_{tr}$, above/below transition, and the stability table — and
  then stops right before the interesting part. At minimum: the phase jump
  $\phi_s\to\pi-\phi_s$, the non-adiabatic time, bunch-length blow-up, and why
  electron machines never see it. Half a page.
- **[gap]** Bucket area / bucket-filling factor and the moving-bucket factor
  $\alpha(\phi_s)$ are not given, although the separatrix is plotted. The
  stationary bucket height is in the pendulum table but only for $\phi_s=0$.
- **[gap]** No mention of RF bunch length $\leftrightarrow$ energy spread
  relation $\sigma_z = \frac{|\eta| c\,\sigma_\delta}{\omega_s}$, which is what
  the whole chapter is for in practice.
- **[polish]** The `longitudinal_map` docstring says "slip factor held constant"
  — good — but the acceleration section then uses it to illustrate a case where
  $\beta^2E_0$ changes, which the function does *not* model (the reference energy
  never ramps inside the map). The "spiral outward" behaviour shown is therefore
  a property of the large-amplitude nonlinearity, not of acceleration. Either
  add reference-energy ramping to the map or reword the section.
- **[polish]** `sin_φs=0.5` is passed while $\phi_s$ is separately computed as
  `asin(sin_φs)` — for the $\pi-\phi_s$ branch the map still only sees
  `sin_φs`, which is correct but subtle. A comment would help.

### 1.10 `longitudinal_dynamics/linac_dynamics.md`

- **[gap/major]** **RF transverse defocusing is missing.** The central design
  tension of a linac is that the same $\phi_s$ that gives longitudinal focusing
  ($\cos\phi_s>0$) gives transverse *de*focusing
  ($\Delta p_r \propto -\frac{\pi e E_0 T L r \sin\phi_s}{\lambda\,\gamma^2\beta^2 mc^3}$,
  the Panofsky–Wenzel consequence), and that it dies off like $1/\gamma^2$. A
  chapter titled "Dynamics in a Linac Accelerator" that omits this is missing its
  punchline. Strongly recommend adding it, with a note on why it drives
  low-energy linac focusing lattices (and RFQs).
- **[polish]** Sign/phase-convention consistency: `rf_acceleration.md` says
  "$z>0$ means the particle arrives early", while this chapter's narrative is
  "a particle arriving late gains more voltage … arrives earlier". Both are
  defensible but the reader has to re-derive the convention. Add a single
  convention box early in the longitudinal part and refer back to it.
- **[gap]** No mention of the *synchronous-phase convention split*: linac people
  usually measure $\phi_s$ from the crest (so $\phi_s<0$, e.g. $-20^\circ$),
  ring people from the zero crossing. Students reading TRACE-3D or IMPACT output
  next to these notes will be confused.
- **[gap]** The adiabatic damping statement ("the oscillation adiabatically
  damps") deserves the scaling: $\Delta\phi\propto(\beta_s\gamma_s)^{-3/4}$,
  $\Delta E\propto(\beta_s\gamma_s)^{3/4}$.
- **[polish]** `track_linac` uses `l = β·λ/2`, i.e. a $\pi$-mode structure. Say
  so, and mention the $\beta\lambda$ ($2\pi$-mode) alternative — it connects
  directly to your earlier, very good "proton linacs must stretch their cell
  lengths" remark in `relativistic_mechanics.md`.

## 2. Course scaffolding (the biggest structural gap)

These notes read as an excellent *textbook draft* but not yet as *course
material* for PHY 862.

- **[gap] No exercises anywhere.** MyST has `{exercise}` / `{solution}`
  directives with `:class: dropdown` — ideal here, because half your exercises
  can be "change this parameter in the cell above and explain what you see".
  Suggest 4–8 per chapter, mixing analytic and computational. This is the single
  highest-value addition.
- **[gap] No references.** Add a `content/references.md` with Wiedemann,
  S.Y. Lee, Conte & MacKay, Wolski (*Beam Dynamics in High Energy Particle
  Accelerators*), Chao's Handbook, and the CAS/USPAS proceedings — and use
  MyST's BibTeX support (`references.bib` + `{cite}`) so chapter-level pointers
  ("Lee §2.4 covers this in more depth") can be inline.
- **[gap] No learning objectives.** A three-bullet "after this chapter you can…"
  admonition at the top of each page is cheap and greatly helps students
  self-assess.
- **[gap] No notation / symbol table.** Given the book deliberately mixes
  analytic conventions ($x'$, $\delta_P$) with TrackPad's ($p_x$, $\delta_E$,
  $z=s/\beta_0-ct$), a single `content/notation.md` — and a link to it from
  every chapter — is close to mandatory.
- **[gap] No chapter summaries.** A "key results" box at the end of each chapter
  (the 5–8 equations a student must be able to reproduce) turns the notes into a
  study resource.
- **[gap] Out-of-scope statement.** The book currently omits: synchrotron
  radiation and radiation damping, space charge, resonances and the tune diagram,
  injection/extraction, instabilities and impedance, beam instrumentation and
  measurement, dynamic aperture. Several of these are referenced in passing
  ("octupoles damp collective effects", "dynamic-aperture problem", "sextupoles
  correct chromaticity but introduce nonlinearity") without ever being defined.
  Either add a short "what comes next" chapter or an explicit scope note in
  `index.md`.
- **[gap] Cross-references are unused.** Every figure has a `:name:` but no
  `{numref}` / `[](#fig:...)` reference points at it anywhere in the prose, so
  the labels do nothing. Same for equations — none are numbered.
  Turn on numbering in `myst.yml`:
  ```yaml
  project:
    numbering:
      headings: true
      equation: true
      figure: true
  ```
  and start labelling the ~15 equations you actually refer back to (Hill's
  equation, the Twiss matrix, the stability condition, the turn-by-turn map).

## 3. Build, reproducibility and repo hygiene

- **[bug] The git repository has no commits.** `git log` reports
  *"your current branch 'main' does not have any commits yet"*. Everything in
  `content/` is currently unversioned. Commit now.
- **[polish] Build cost.** The chromaticity-correction widget in
  `emittance_coupling_dispersion.md` has a $21\times21$ slider grid and evaluates
  13 closed-orbit + tune solves per grid point — roughly 5,700 closed-orbit
  solves at build time, plus a `getchrom` per point. This is very likely the
  dominant build cost of the whole book. Consider $11\times11$, or caching, or
  fewer $\delta$ points.
- **[polish] Repeated `using` blocks.** Nearly every cell re-imports
  `StaticArrays, TrackPad, TrackPadWidgets`. Harmless but noisy; a single setup
  cell per page (tagged `remove-cell`) would be cleaner.
- **[polish] Unused imports.** e.g. `using StaticArrays` in cells that never use
  an `SVector`/`SMatrix`.
- **[bug] `README.md` has a duplicated fragment**: "It tracks the TrackPad.jl
  development checkout: / tracks the TrackPad.jl development checkout:".
- **[bug] Inconsistent repository URLs.** `myst.yml` and `README.md` point at
  `github.com/haoyue/...`; `content/index.md` points at
  `github.com/MSU-Beam-Dynamics/TrackPad.jl`. Pick the canonical ones.
- **[bug] `index.md` build instructions are wrong.** It gives
  `uv run jupyter-book start` / `build` with no `--execute`, while the README
  correctly explains that `--execute` is *required* or no cell output appears.
  Fix `index.md` (or, better, have it link to the README rather than duplicate).
- **[bug] `index.md` mislabels part 3** as "Longitudinal Dynamics in a Ring" —
  the part also contains the linac chapter.
- **[polish] `myst.yml`** has no `license`, no `keywords`, no `numbering`, no
  `math` macros block. Defining macros once (e.g. `\Brho`, `\dE`) would remove a
  lot of repetition and enforce notation consistency.
- **[polish] Figure licensing.** `Permeability_of_ferromagnet_by_Zureks.svg` is a
  Wikimedia image; the caption should carry the author/CC attribution if the book
  is to be published. Worth auditing the other borrowed figures
  (`ags_ring.png`, `rf_cavity.png`, `H_type_and_C_Type_dipole.png`) the same way.
- **[polish] Accessibility.** No `alt` text on any figure. MyST supports
  `:alt:` on `{figure}`.
- **[polish] Print/PDF degradation.** The `explorer` widgets are `text/html` and
  will render as nothing in a PDF export. If a PDF is ever wanted, each widget
  cell should also emit a static fallback figure at its default slider position.
